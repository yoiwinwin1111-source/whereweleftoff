# 再次重逢的初恋 · Where we left off

Buildless single-file interactive fiction. Deploy the repository root to Vercel as an Other/static project. Entry: `index.html`. No build command or API keys required.

## Play
- Enter a player name, swipe up and enter `0000`.
- KakaoTalk advances six chapters through explicit response choices; free text is saved locally.
- Chapter four requires completing the Instagram simulated call before proceeding.
- Phone call history, public fictional X posts with comments, a local private account, notes, and chapter replay are available.
- Spotify-style player produces three original ambient chords using Web Audio; it does not contain copyrighted song recordings.
- Progress and name live in localStorage under `whereweleftoff.v1`.
