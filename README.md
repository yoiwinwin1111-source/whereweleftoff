# 再次重逢的初恋 · Where we left off

Buildless single-file interactive fiction. Deploy the repository root to Vercel as an Other/static project. Entry: `index.html`. No build command or API keys required.

## Play
- Confirm or enter a player name on every visit, swipe up and enter `0000`. Different names start separate fresh progress; v1 test data is never imported. Rename from the desktop chip or Settings.
- KakaoTalk advances six chapters through explicit response choices; free text is saved locally.
- Chapter four requires completing the Instagram simulated call before proceeding.
- Contacts include Dohoon, oo and mother, with locally saved chats. Public fictional X trends and comments appear gradually after the program broadcast event. A private account, notes, and chapter replay are available.
- Instagram-style feed uses public TWS profile photos and BIGHIT BTS Proof concept photos. It does not forge original captions or relationship evidence.
- Spotify-style player uses official Apple Music previews for BTS Spring Day, SHINee Replay, Girls' Generation Gee and BIGBANG Haru Haru, with full-song links. Previews are usually about 30 seconds; no full recordings are hosted.
- Progress and name live in localStorage under `whereweleftoff.v2`.
